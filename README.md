## Principes

**Souveraineté** — Aucun projet ne collecte ni ne transmet de données. Ce n'est pas un paramètre, c'est une architecture de départ.

**Zéro dépendance choisie** — HTML, CSS, Python, Raspberry Pi. Chaque outil compris en totalité par son auteur.

**Hébergement libre** — GitHub Pages ou Pi local. Déploiement en un push, zéro plateforme imposée.

**Forme = message** — Un site sur la maîtrise numérique qui est lui-même maîtrisé.
